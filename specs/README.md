## ของกลาง
ของที่ใช้ร่วมหลายฟีเจอร์ (Constraint, data model, glossary) อยู่ที่ `000-shared/` เขียนที่เดียว spec ของฟีเจอร์อ้าง ID (ดูวิธีใน `docs/shared-spec-guide.md`)
ก่อนเริ่มฟีเจอร์ของตัวเอง ให้อ่าน `000-shared/constraints.md` หัวข้อ "คำถามที่กระทบหลายฟีเจอร์" ก่อน

## ขั้นตอนของแต่ละฟีเจอร์ (ทำจากบัญชี GitHub ของเจ้าของฟีเจอร์เอง)
1. สร้าง `specs/00N-<feature>/spec.md` จากหัวข้อ 3.1 ของ `docs/srs/SRS.md` (6 ส่วน + Assumptions & Open Questions)
2. `/clarify` แล้ว commit `00N: spec v2`
3. `/plan` แล้ว commit `00N: plan v1`
4. `/tasks` แล้ว commit `00N: tasks v1` (แตก task ให้ครบทุก AC และทุก Constraint)
5. `/implement T-xx` ทีละ task แล้ว commit `00N: T-xx done`
6. เมื่อทุกฟีเจอร์เสร็จ ใช้ `/verify` ทำ `rtm.md` (อาจารย์สั่งให้ทำหลังทุกอย่างเสร็จ)

ทุกครั้งที่ spec เปลี่ยนเวอร์ชัน เพิ่ม 1 รายการใน `specs/CHANGELOG.md`

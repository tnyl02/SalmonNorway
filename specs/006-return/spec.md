# Feature: บันทึกการรับคืนอุปกรณ์ (Return)
Spec ID: SPEC-RET-006 | Source: US-010, RQ-04, RQ-11, RQ-13, RQ-25 | Use case: UC-09 (รวม UC-07 และ UC-04 ตามคำตอบเจ้าของฟีเจอร์ รอ CR-003)

Backlog: BL-10 (+ BL-16, BL-13 ถ้า CR-003 ผ่าน) (specs/backlog.md)

## Goal
เจ้าหน้าที่บันทึกการรับคืนอุปกรณ์พร้อมระบุสภาพได้ในระบบ เพื่อปิดรอบยืม-คืน
และให้สถานะอุปกรณ์กลับมาถูกต้องโดยอัตโนมัติ (ว่าง หรือ ไม่พร้อมใช้งาน) โดยเจ้าหน้าที่ไม่ต้องไปแก้สถานะเอง
นักศึกษาจึงเห็นอุปกรณ์ที่คืนแล้วว่ายืมต่อได้ในหน้าตรวจสอบอุปกรณ์ของ 001 (AC-EQS-05)

## Scope
### In scope
- เจ้าหน้าที่หาการยืมที่ยังไม่คืนด้วยรหัสครุภัณฑ์ หรือจากหน้ารายการที่ยังไม่คืน (เฉพาะอุปกรณ์ภาควิชาตนเอง)
- บันทึกการรับคืนพร้อมระบุสภาพ ปกติ / ชำรุด และแนบรูปภาพสภาพอุปกรณ์ทุกครั้ง
- เปลี่ยนสถานะอุปกรณ์อัตโนมัติตามสภาพที่คืน
- บันทึกว่าการยืมนั้นคืนเกินกำหนด และแสดงให้เจ้าหน้าที่เห็น
- บันทึกประวัติการรับคืนตาม DOM-AUDIT-01
### Out of scope
- นักศึกษาแจ้งคืนหรือบันทึกคืนเอง (UC-04 รวมเข้ากับ UC-09 แล้ว เจ้าหน้าที่เป็นผู้บันทึกเท่านั้น รอ CR-003)
- ปิดการยืมกรณีอุปกรณ์สูญหาย (เสนอเป็น FR ใหม่ใน CR-003 ดู Q-01)
- ระงับคำขอยืมที่ค้างและแจ้งผู้ขอเมื่ออุปกรณ์คืนมาชำรุด (เสนอใน CR-003 ดู Q-08)
- บันทึกการส่งมอบและการสร้างกำหนดคืน (UC-08, 005)
- ซ่อมอุปกรณ์ชำรุดแล้วเปลี่ยนกลับเป็น "ว่าง" (UC-10 จัดการรายการอุปกรณ์)
- กำหนดหรือบันทึกบทลงโทษเมื่อคืนเกินกำหนด (RQ-27, Q-SH-07)
- รายงานประวัติการคืนเกินกำหนดรายผู้ยืม (RQ-07, UC-13) และปฏิเสธคำขอใหม่อัตโนมัติ (RQ-20, 002)
  ฟีเจอร์นี้แค่บันทึกข้อมูลที่ทั้งสองใช้
- การแจ้งเตือน (RQ-12, IF-NOT-01)
- ยืนยันตัวตน (IF-IDP-01) ถือว่าทำสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)

## Requirements
- FR-RET-01 ระบบต้องให้เจ้าหน้าที่เลือกการยืมที่ยังไม่คืนของอุปกรณ์รายชิ้นเพื่อบันทึกการรับคืน ได้ 2 ทาง:
  (ก) กรอกรหัสครุภัณฑ์ (ทางหลัก) (ข) เลือกจากหน้ารายการการยืมที่ยังไม่คืน
  บันทึกได้เฉพาะอุปกรณ์สถานะ "ถูกยืม" ที่มีการยืม (DM-05) ที่ยังไม่คืน และเป็นอุปกรณ์ของภาควิชาเดียวกับเจ้าหน้าที่
  (ภาควิชาจาก IF-IDP-01)                                                     <- RQ-11, UC-09, data-model.md, ASM-03
- FR-RET-02 ระบบต้องบันทึกเวลาคืนลงในการยืม เป็นเวลาของระบบตอนบันทึกสำเร็จ (Asia/Bangkok) เจ้าหน้าที่แก้ไม่ได้
  และต้องให้เจ้าหน้าที่ระบุสภาพของอุปกรณ์ 1 ใน 2 ค่า: ปกติ, ชำรุด (สูญหายไม่ใช่สภาพ ดู Q-01)
  test แยกเป็นเรื่องเวลาคืน (AC-RET-09) และเรื่องสภาพ (AC-RET-04)                <- RQ-11, ASM-04
- FR-RET-03 เมื่อสภาพเป็น "ปกติ" ระบบต้องเปลี่ยนสถานะอุปกรณ์เป็น "ว่าง" อัตโนมัติหลังบันทึกการรับคืนสำเร็จ   <- RQ-13, US-010
- FR-RET-04 เมื่อสภาพเป็น "ชำรุด" ระบบต้องเปลี่ยนสถานะอุปกรณ์เป็น "ไม่พร้อมใช้งาน" หลังบันทึกการรับคืนสำเร็จ
  โดยไม่ผ่านสถานะ "ว่าง"                                                     <- RQ-11, UC-07, ASM-05 (รอ CR-003)
- FR-RET-05 ระบบต้องให้เจ้าหน้าที่แนบรูปภาพสภาพอุปกรณ์หลังการยืมทุกครั้งที่บันทึกการรับคืน ทั้งยืมแบบปกติและค้างคืน
  อย่างน้อย 1 รูป สูงสุด 5 รูป ชนิด JPG หรือ PNG ขนาดไม่เกิน 5 MB ต่อรูป ถ้าไม่ครบเงื่อนไขระบบต้องไม่บันทึก
                                                                            <- RQ-04, UC-07, ASM-06 (รอ CR-003)
- FR-RET-06 เมื่อเวลาคืนเกินกำหนดคืนที่บันทึกไว้ในการยืม ระบบต้องบันทึกว่าการยืมนั้นคืนเกินกำหนด
  เจ้าหน้าที่ต้องเห็นเครื่องหมายนี้ในหน้ารายละเอียดการยืม และเห็นการยืมที่เลยกำหนดคืนแล้วในหน้ารายการที่ยังไม่คืน
  (ผู้ยืมเห็นเฉพาะของตนเอง แสดงที่ไหน ดู Q-03)                                  <- ASM-07, ข้อมูลให้ RQ-07, RQ-20
- FR-RET-07 ระบบต้องบันทึกประวัติการรับคืนทุกครั้งตาม DOM-AUDIT-01                 <- RQ-25, DOM-AUDIT-01

## Quality Requirements
- NFR-DATA-01 (SRS 3.3) สถานะหลังรับคืนต้องเห็นในหน้าตรวจสอบอุปกรณ์ของ 001 ภายใน 30 วินาที
  ตรวจโดย AC-EQS-05 ของ 001 ฟีเจอร์นี้ต้องเขียนฐานข้อมูลทันที (ไม่มี batch หรือหน่วงเวลา)
- NFR-SEC-01 (SRS 3.3) TLS 1.2 ขึ้นไป และต้องยืนยันตัวตนก่อนทุกครั้ง
- NFR-AVAIL-01 (SRS 3.3) พร้อมใช้งานอย่างน้อย 99% ช่วง 08.30-16.30 น. วันจันทร์-ศุกร์

## Acceptance Criteria
- [ ] AC-RET-01 (FR-RET-03)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ถูกยืม" มีการยืมที่ยังไม่คืน
      When  เจ้าหน้าที่บันทึกการรับคืน สภาพ "ปกติ" พร้อมรูป 1 รูป
      Then  การยืมนั้นมีเวลาคืน และสถานะอุปกรณ์เป็น "ว่าง"
- [ ] AC-RET-02 (FR-RET-04)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ถูกยืม" มีการยืมที่ยังไม่คืน
      When  เจ้าหน้าที่บันทึกการรับคืน สภาพ "ชำรุด" พร้อมรูป 1 รูป
      Then  การยืมนั้นมีเวลาคืน และสถานะอุปกรณ์เป็น "ไม่พร้อมใช้งาน" ไม่เคยเป็น "ว่าง" ระหว่างทาง
- [ ] AC-RET-03 (FR-RET-01)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ว่าง" หรือ "ไม่พร้อมใช้งาน" (ไม่มีการยืมที่ยังไม่คืน)
      When  เจ้าหน้าที่กรอกรหัสครุภัณฑ์ของชิ้นนั้นเพื่อบันทึกการรับคืน
      Then  ระบบไม่บันทึก แจ้งว่าอุปกรณ์นี้ไม่มีการยืมที่ยังไม่คืน และสถานะอุปกรณ์ไม่เปลี่ยน
- [ ] AC-RET-04 (FR-RET-02 สภาพ)
      Given เจ้าหน้าที่กำลังบันทึกการรับคืน
      When  ไม่ได้ระบุสภาพ แล้วกดบันทึก
      Then  ระบบไม่บันทึก แจ้งให้เลือกสภาพ ปกติ หรือ ชำรุด และไม่มีตัวเลือก "สูญหาย"
- [ ] AC-RET-05 (FR-RET-05 แนบสำเร็จ)
      Given เจ้าหน้าที่กำลังบันทึกการรับคืน
      When  แนบรูป JPG 1 รูป และ PNG 4 รูป แต่ละรูปไม่เกิน 5 MB แล้วบันทึก
      Then  บันทึกสำเร็จ รูปทั้ง 5 รูปถูกเก็บคู่กับการรับคืนครั้งนั้น และเปิดดูภายหลังได้
- [ ] AC-RET-06 (FR-RET-06, DOM-LOAN-01)
      Given การยืมแบบปกติ กำหนดคืน 2569-10-10 16:00
      When  ระบบบันทึกการรับคืนเวลา 2569-10-10 17:00 และอีกกรณีบันทึกเวลา 2569-10-10 15:00
      Then  กรณี 17:00 การยืมถูกบันทึกว่าคืนเกินกำหนด กรณี 15:00 ไม่ถูกบันทึก
- [ ] AC-RET-07 (FR-RET-07, DOM-AUDIT-01)
      Given เจ้าหน้าที่บันทึกการรับคืนสำเร็จ
      When  การบันทึกเสร็จสิ้น
      Then  มี audit log ของการรับคืนครั้งนั้นตามที่ DOM-AUDIT-01 กำหนด
- [ ] AC-RET-08 (FR-RET-01, IF-IDP-01)
      Given นักศึกษายืนยันตัวตนแล้ว
      When  เรียกบันทึกการรับคืน หรือเปิดหน้ารายการที่ยังไม่คืนโดยตรง
      Then  ระบบปฏิเสธว่าไม่มีสิทธิ์ และไม่มีข้อมูลการยืมถูกส่งกลับหรือเปลี่ยน
- [ ] AC-RET-09 (FR-RET-02 เวลาคืน)
      Given เวลาของระบบคือ 2569-10-10 14:30 (Asia/Bangkok)
      When  เจ้าหน้าที่บันทึกการรับคืนสำเร็จ โดยส่งเวลาอื่นมาด้วย (เช่น 2569-10-10 09:00)
      Then  เวลาคืนในการยืมเป็น 2569-10-10 14:30 ตามเวลาของระบบ ไม่ใช่เวลาที่ส่งมา
- [ ] AC-RET-10 (FR-RET-01 หน้ารายการ)
      Given ภาควิชาของเจ้าหน้าที่มีการยืมที่ยังไม่คืน 3 รายการ คืนแล้ว 2 รายการ และภาควิชาอื่นมีการยืมที่ยังไม่คืน 1 รายการ
      When  เจ้าหน้าที่เปิดหน้ารายการที่ยังไม่คืน
      Then  เห็นเฉพาะ 3 รายการของภาควิชาตนเอง และเลือกรายการเพื่อบันทึกการรับคืนได้
- [ ] AC-RET-11 (FR-RET-01 ภาควิชา)
      Given อุปกรณ์ "ถูกยืม" เป็นของภาควิชาอื่น
      When  เจ้าหน้าที่กรอกรหัสครุภัณฑ์ของชิ้นนั้นเพื่อบันทึกการรับคืน
      Then  ระบบปฏิเสธว่าไม่มีสิทธิ์ และการยืมกับสถานะอุปกรณ์ไม่เปลี่ยน
- [ ] AC-RET-12 (FR-RET-05 ไม่ครบเงื่อนไข)
      Given เจ้าหน้าที่กำลังบันทึกการรับคืน
      When  (ก) ไม่แนบรูป (ข) แนบ 6 รูป (ค) แนบไฟล์ GIF (ง) แนบ JPG ขนาดเกิน 5 MB แล้วบันทึก (แยกกรณี)
      Then  ทุกกรณีระบบไม่บันทึก แจ้งเหตุผลที่ไม่ผ่าน และการยืมกับสถานะอุปกรณ์ไม่เปลี่ยน
- [ ] AC-RET-13 (FR-RET-06 การแสดงผล)
      Given การยืมรายการหนึ่งคืนเกินกำหนดแล้ว และอีกรายการยังไม่คืนแต่เลยกำหนดคืนแล้ว
      When  เจ้าหน้าที่เปิดหน้ารายละเอียดการยืมรายการแรก และเปิดหน้ารายการที่ยังไม่คืน
      Then  หน้ารายละเอียดแสดงว่าคืนเกินกำหนด และหน้ารายการที่ยังไม่คืนแสดงว่ารายการที่สองเลยกำหนดคืน

## Assumptions & Open Questions
- ASM-01 การยืมทุกรายการ (รวมยืมค้างคืน) มีกำหนดคืน (วันที่และเวลา) ที่ 005 บันทึกไว้ตอนส่งมอบเสมอ
  ฟีเจอร์นี้อ่านกำหนดคืนจากการยืมเท่านั้น ไม่คำนวณเอง (ทีมตัดสิน 2569-11-10 ปิด Q-05)
- ASM-02 ระหว่างรอ Q-SH-03 ใช้ auth จำลองของ 001 (T-03) ระบุบทบาทเจ้าหน้าที่
- ASM-03 เจ้าหน้าที่บันทึกการรับคืนได้เฉพาะอุปกรณ์ของภาควิชาตนเอง หาได้ทั้งจากรหัสครุภัณฑ์และหน้ารายการที่ยังไม่คืน
  (ทีมตัดสิน 2569-11-10 ปิด Q-06 ยังไม่ได้ยืนยันกับเจ้าหน้าที่)
- ASM-04 เวลาคืนคือเวลาของระบบตอนบันทึก เจ้าหน้าที่แก้ไม่ได้ (ทีมตัดสิน 2569-11-10 ยังไม่ได้ยืนยันกับเจ้าหน้าที่)
- ASM-05 คืนมาชำรุดแล้วสถานะเป็น "ไม่พร้อมใช้งาน" ตาม CON-DATA-01 (ไม่มีสถานะ "ส่งซ่อม")
  (ทีมตัดสิน 2569-11-10 ยังไม่ได้ยืนยันกับเจ้าหน้าที่)
- ASM-06 รูปบังคับทุกครั้ง 1 ถึง 5 รูป JPG/PNG ไม่เกิน 5 MB ต่อรูป (ทีมตัดสิน 2569-11-10 ปิด Q-02 ยังไม่ได้ยืนยันกับเจ้าหน้าที่)
- ASM-07 เจ้าหน้าที่เห็นเครื่องหมายคืนเกินกำหนดในหน้ารายละเอียดการยืมและหน้ารายการที่ยังไม่คืน
  (ทีมตัดสิน 2569-11-10 ยังไม่ได้ยืนยันกับเจ้าหน้าที่)

  และสถานะอุปกรณ์เป็น "ไม่พร้อมใช้งาน" (เหตุ: สูญหาย) เป็น FR ใหม่ ต้องผ่าน CR-003 -> ทีม แล้วยืนยันกับเจ้าหน้าที่

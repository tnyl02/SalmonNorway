## Goal
เจ้าหน้าที่บันทึกการรับคืนอุปกรณ์พร้อมระบุสภาพได้ในระบบ เพื่อปิดรอบยืม-คืน
และให้สถานะอุปกรณ์กลับมาถูกต้องโดยอัตโนมัติ (ว่าง หรือ ไม่พร้อมใช้งาน) โดยเจ้าหน้าที่ไม่ต้องไปแก้สถานะเอง
นักศึกษาจึงเห็นอุปกรณ์ที่คืนแล้วว่ายืมต่อได้ในหน้าตรวจสอบอุปกรณ์ของ 001 (AC-EQS-05)

## Scope
### In scope
- เจ้าหน้าที่เลือกการยืมที่ยังไม่คืน แล้วบันทึกการรับคืนพร้อมระบุสภาพ ปกติ / ชำรุด
- เปลี่ยนสถานะอุปกรณ์อัตโนมัติตามสภาพที่คืน
- แนบรูปภาพสภาพอุปกรณ์ตอนรับคืน (RQ-04, ส่วนของ UC-07 รอ CR)
- บันทึกว่าการยืมนั้นคืนเกินกำหนด เมื่อเวลาคืนเกินกำหนดคืน
- บันทึกประวัติการรับคืน (RQ-25)
### Out of scope
- นักศึกษาแจ้งคืนหรือบันทึกคืนเอง (UC-04 รวมเข้ากับ UC-09 แล้ว เจ้าหน้าที่เป็นผู้บันทึกเท่านั้น รอ CR)
- บันทึกการส่งมอบและการสร้างกำหนดคืน (UC-08, 005)
- ซ่อมอุปกรณ์ชำรุดแล้วเปลี่ยนกลับเป็น "ว่าง" (UC-10 จัดการรายการอุปกรณ์)
- กำหนดหรือบันทึกบทลงโทษเมื่อคืนเกินกำหนด (RQ-27, Q-SH-07)
- แสดงประวัติการคืนเกินกำหนดให้เจ้าหน้าที่ดู (RQ-07, UC-13) และปฏิเสธคำขอใหม่อัตโนมัติ (RQ-20, 002)
  ฟีเจอร์นี้แค่บันทึกข้อมูลที่ทั้งสองใช้
- การแจ้งเตือน (RQ-12, IF-NOT-01)
- ยืนยันตัวตน (IF-IDP-01) ถือว่าทำสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)

## Requirements
- FR-RET-01 ระบบต้องให้เจ้าหน้าที่เลือกการยืมที่ยังไม่คืนของอุปกรณ์รายชิ้น เพื่อบันทึกการรับคืน
  บันทึกได้เฉพาะอุปกรณ์สถานะ "ถูกยืม" ที่มีการยืม (DM-05) ที่ยังไม่คืน          <- RQ-11, UC-09, data-model.md
- FR-RET-02 ระบบต้องบันทึกเวลาคืนลงในการยืม และต้องให้เจ้าหน้าที่ระบุสภาพของอุปกรณ์ 1 ใน 2 ค่า: ปกติ, ชำรุด
  สูญหายไม่ใช่สภาพ บันทึกเป็นการคืนไม่ได้ (ดู Q-01)                             <- RQ-11, Clarifications 2569-11-10
- FR-RET-03 เมื่อสภาพเป็น "ปกติ" ระบบต้องเปลี่ยนสถานะอุปกรณ์เป็น "ว่าง" อัตโนมัติหลังบันทึกการรับคืนสำเร็จ   <- RQ-13, US-010
- FR-RET-04 เมื่อสภาพเป็น "ชำรุด" ระบบต้องเปลี่ยนสถานะอุปกรณ์เป็น "ไม่พร้อมใช้งาน" หลังบันทึกการรับคืนสำเร็จ
  โดยไม่ผ่านสถานะ "ว่าง"                                                     <- RQ-11, UC-07, Clarifications 2569-11-10 (รอ CR ดู Q-07)
- FR-RET-05 ระบบต้องให้เจ้าหน้าที่แนบรูปภาพสภาพอุปกรณ์หลังการยืมในขั้นตอนรับคืน
  ทั้งการยืมแบบปกติและแบบค้างคืน (บังคับหรือไม่ ดู Q-02)                         <- RQ-04, UC-07 (รอ CR ดู Q-07)
- FR-RET-06 เมื่อเวลาคืนเกินกำหนดคืนที่บันทึกไว้ในการยืม ระบบต้องบันทึกว่าการยืมนั้นคืนเกินกำหนด
  (ใครเห็น ดู Q-03)                                                         <- Clarifications 2569-11-10, ข้อมูลให้ RQ-07, RQ-20
- FR-RET-07 ระบบต้องบันทึกประวัติการรับคืนทุกครั้ง: เจ้าหน้าที่ผู้บันทึก เวลา รหัสครุภัณฑ์ สภาพ
  และสถานะอุปกรณ์ก่อน/หลัง                                                   <- RQ-25, DOM-AUDIT-01

## Quality Requirements
- NFR-DATA-01 (SRS 3.3) สถานะหลังรับคืนต้องเห็นในหน้าตรวจสอบอุปกรณ์ของ 001 ภายใน 30 วินาที
  ตรวจโดย AC-EQS-05 ของ 001 ฟีเจอร์นี้ต้องเขียนฐานข้อมูลทันที (ไม่มี batch หรือหน่วงเวลา)
- NFR-SEC-01 (SRS 3.3) TLS 1.2 ขึ้นไป และต้องยืนยันตัวตนก่อนทุกครั้ง
- NFR-AVAIL-01 (SRS 3.3) พร้อมใช้งานอย่างน้อย 99% ช่วง 08.30-16.30 น. วันจันทร์-ศุกร์

## Acceptance Criteria
- [ ] AC-RET-01 (FR-RET-01, FR-RET-02, FR-RET-03)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ถูกยืม" มีการยืมที่ยังไม่คืน
      When  เจ้าหน้าที่บันทึกการรับคืน สภาพ "ปกติ"
      Then  การยืมนั้นมีเวลาคืน และสถานะอุปกรณ์เป็น "ว่าง"
- [ ] AC-RET-02 (FR-RET-04)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ถูกยืม" มีการยืมที่ยังไม่คืน
      When  เจ้าหน้าที่บันทึกการรับคืน สภาพ "ชำรุด"
      Then  การยืมนั้นมีเวลาคืน และสถานะอุปกรณ์เป็น "ไม่พร้อมใช้งาน" ไม่เคยเป็น "ว่าง" ระหว่างทาง
- [ ] AC-RET-03 (FR-RET-01)
      Given อุปกรณ์ชิ้นหนึ่งสถานะ "ว่าง" หรือ "ไม่พร้อมใช้งาน" (ไม่มีการยืมที่ยังไม่คืน)
      When  เจ้าหน้าที่พยายามบันทึกการรับคืนอุปกรณ์ชิ้นนั้น
      Then  ระบบไม่บันทึก แจ้งว่าอุปกรณ์นี้ไม่มีการยืมที่ยังไม่คืน และสถานะอุปกรณ์ไม่เปลี่ยน
- [ ] AC-RET-04 (FR-RET-02)
      Given เจ้าหน้าที่กำลังบันทึกการรับคืน
      When  ไม่ได้ระบุสภาพ แล้วกดบันทึก
      Then  ระบบไม่บันทึก แจ้งให้เลือกสภาพ ปกติ หรือ ชำรุด และไม่มีตัวเลือก "สูญหาย"
- [ ] AC-RET-05 (FR-RET-05)
      Given เจ้าหน้าที่กำลังบันทึกการรับคืน
      When  แนบรูปภาพสภาพอุปกรณ์ แล้วบันทึกสำเร็จ
      Then  รูปนั้นถูกเก็บคู่กับการรับคืนครั้งนั้น และเปิดดูภายหลังได้
- [ ] AC-RET-06 (FR-RET-06, DOM-LOAN-01)
      Given การยืมแบบปกติ กำหนดคืน 2569-10-10 16:00
      When  เจ้าหน้าที่บันทึกการรับคืนเวลา 2569-10-10 17:00 และอีกกรณีบันทึกเวลา 2569-10-10 15:00
      Then  กรณี 17:00 การยืมถูกบันทึกว่าคืนเกินกำหนด กรณี 15:00 ไม่ถูกบันทึก
- [ ] AC-RET-07 (FR-RET-07, DOM-AUDIT-01)
      Given เจ้าหน้าที่บันทึกการรับคืนสำเร็จ
      When  การบันทึกเสร็จสิ้น
      Then  มีประวัติที่ระบุเจ้าหน้าที่ผู้บันทึก เวลา รหัสครุภัณฑ์ สภาพ และสถานะอุปกรณ์ก่อน/หลัง
- [ ] AC-RET-08 (FR-RET-01, IF-IDP-01)
      Given นักศึกษายืนยันตัวตนแล้ว
      When  เรียกบันทึกการรับคืนโดยตรง
      Then  ระบบปฏิเสธว่าไม่มีสิทธิ์ และไม่มีข้อมูลการยืมหรือสถานะอุปกรณ์เปลี่ยน
